# Metagent Finance — Brand Assets

Logo derived from the in-app mark: a glowing **cyan hexagon** (the cryptographic
permission boundary) with an **"M" monogram**.

## Palette
| Role | Hex |
|------|-----|
| Primary cyan (mark) | `#00f0ff` |
| Cyan highlight | `#7df9ff` |
| Cyan deep | `#00b3c6` |
| Background (dark) | `#10131a` |
| Mark cut-out / ink | `#0a0d13` |

## Files
| File | Size | Use |
|------|------|-----|
| `metagent-icon-dark-1024.png` | 1024² | **Primary submission logo** — square, dark background |
| `metagent-icon-dark-512.png` | 512² | App/profile icon, dark surfaces |
| `metagent-icon-256.png` | 256² | Favicon / small avatar |
| `metagent-icon-transparent-1024.png` | 1024² | Overlay on any background |
| `metagent-icon-transparent-512.png` | 512² | Overlay, smaller |
| `metagent-logo-full.png` | 1149×356 | Horizontal lockup — wordmark + tagline |
| `metagent-icon.svg` | vector | Source — scale to any size |

**For the hackathon submission, use `metagent-icon-dark-1024.png`** (square logos
are the standard requirement). Use `metagent-logo-full.png` for the cover/banner.
